# Ecommerce Analytics Project
# E-Commerce Sales & Customer Intelligence Dashboard

## 📌 Overview
An end-to-end data analytics project analyzing ~100k real e-commerce orders
(Olist Brazilian E-Commerce dataset) to uncover sales trends, customer value,
and delivery/review performance — with insights delivered via an interactive
dashboard.

## ❓ Business Questions
1. What are the sales trends over time (monthly/seasonal patterns)?
2. Which product categories and regions generate the most revenue?
3. Who are the high-value customers? (RFM segmentation)
4. What's driving late deliveries, and how does that affect review scores?
5. What's the customer retention / repeat purchase rate?

## 🛠 Tech Stack
- **Python** (pandas, numpy, matplotlib, seaborn) — data cleaning & EDA
- **SQL** (PostgreSQL) — data storage, joins, aggregations
- **Python** — RFM segmentation, cohort analysis
- **Power BI / Tableau** — interactive dashboard
- **Git/GitHub** — version control
- *(Stretch)* **Streamlit** — live interactive web app
